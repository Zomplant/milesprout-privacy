# MileSprout privacy policy

Public policy page for MileSprout, published by ZomPlant Apps. This repository contains only the policy website, not the Android application.

The policy text matches MileSprout-privacy-policy.md in the application project. Keep both copies synchronized when data handling changes. The website footer separately describes GitHub Pages hosting.

GitHub Pages publishes the root of the main branch. No analytics, external fonts, scripts, or forms are included.
